# Dhaneshkumar — Software Engineer Portfolio

A responsive, dark-themed personal portfolio built with React, TypeScript and Vite.

## Start locally

1. Install Node.js 20.19+ or 22.12+.
2. Run `npm install`.
3. Run `npm run dev` and open the URL shown in your terminal.
4. Run `npm run build` to generate the deployable `dist/` folder.

## Add your professional photo

Copy your own resume photo to `public/photo.jpg`. The hero section automatically displays it in place of the temporary initials placeholder. Use a portrait-oriented image, ideally at least 800 × 1000 pixels.

## Personalize before publishing

- Confirm the case-study wording and employer confidentiality requirements.
- Add your verified LinkedIn and GitHub profile URLs if you want them displayed (not included because they were not available in the CV text).
- The downloadable CV is at `public/Dhaneshkumar_CV.docx`. Review whether you want your phone number publicly downloadable.
- Consider replacing it with a recruiter-friendly PDF version.
- Confirm whether the stated employment details, work authorization, and availability are current before adding them.
- Review German Impressum and privacy requirements; the website deliberately includes no analytics or tracking scripts.
- No contact form is used; contact is via mailto links.

## Deploy to Cloudflare Pages

1. Create a **private** GitHub repository and push this folder.
2. In Cloudflare Dashboard → Workers & Pages → Create application → Pages → Connect to Git, authorize your repository.
3. Framework preset: **Vite**. Build command: `npm run build`. Build output directory: `dist`.
4. Deploy. Your website receives a public `pages.dev` URL. Future pushes trigger redeployment.

Hosting service pricing and plan limits may change. Check Cloudflare's current terms before deployment.

Experience, skills, education and certification were adapted from the provided 2026 CV. Project descriptions are high-level summaries, not claims of public repositories. No employer source code is included.
